# SentientWeb Light Editorial Section Theme

This export contains the light-background theme settings for the **Editorial Magazine Alternation** direction.

Use this theme for sections that should feel like readable magazine/proof pages:

- hero / opening clarity section
- use-case storyboard chapters
- customer proof
- integration logo strip
- case-study or workflow explanation sections

Keep the dark theme for engine-like sections:

- profit leak / blackhole cards
- cinematic funnel
- orchestration / system mechanics
- final CTA

## Files

- `light-section-theme.css` - reusable CSS tokens and classes
- `tailwind-class-map.md` - Tailwind class replacements for production JSX
- `CODEX_IMPLEMENTATION_PROMPT.md` - paste-ready prompt for OpenAI Codex

## Core Tokens

```css
--sentient-paper: #f7faf4;
--sentient-paper-warm: #fffdf8;
--sentient-paper-ink: #10213c;
--sentient-paper-muted: rgba(16, 33, 60, 0.68);
--sentient-paper-line: rgba(16, 33, 60, 0.14);
--sentient-paper-green: #0b6a31;
```

## Recommended Rhythm

1. Light: hero / clarity
2. Dark: leak / urgency
3. Light: use-case storyboards
4. Dark: funnel / orchestration
5. Light: integrations / proof
6. Dark: final CTA
