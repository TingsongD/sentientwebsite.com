# SentientWeb Recovery Preview CTA Design Export

This package contains the approved merged, full-width Recovery Preview CTA design.

## Files

- `recovery-preview-cta-design.html` - standalone visual reference.
- `DESIGN_DOC.md` - design intent and implementation notes.
- `CODEX_IMPLEMENTATION_PROMPT.md` - paste-ready prompt for implementing this section in the frontend codebase.

## Design Summary

The section merges the URL scanner, sample output, and spotlight treatment into one full-width diagnostic cockpit. The goal is to make the visitor's primary action unmistakable: paste a public URL and request a recovery preview.

Key approved details:

- Light editorial outer section.
- Dark scanner cockpit as the main interactive surface.
- Script label reads `Scan your URL`.
- `Detected` uses the red warning accent.
- One integrated output area, not two separate cards.
- Rainbow/neon CTA treatment on `Scan my page`.
